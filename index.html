SynceTune

Spotify → YouTube in a few clicks. No login, no keys, free.

Runs entirely in your browser. It reads Spotify's public embed page through a free relay and matches songs via public YouTube search instances (Piped / Invidious) — no account touched, nothing uploaded. Matches are remembered on this device, so running the same playlist again is instant. Public playlists, up to 188 tracks per run.
